Política de privacidade

Dados usados

  • Nome de usuário e informações básicas da conta conectada (escopo user.info.basic).
  • Permissão para publicar vídeos na conta (escopo video.publish).
  • Um token de acesso, guardado criptografado como segredo do repositório privado do canal.

O que não fazemos

  • Não coletamos dados de seguidores, espectadores ou outras pessoas.
  • Não vendemos nem compartilhamos dados com terceiros.
  • Não usamos os dados para anúncios.

Como apagar

Para remover o acesso, desconecte o app nas configurações de segurança do TikTok. O token guardado é apagado em seguida.

English. We only use the connected account's basic info and video publishing permission to post the channel's own videos. The access token is stored encrypted as a secret in the channel's private repository. No data about other people is collected, sold or shared. Access can be revoked at any time in TikTok's security settings.
